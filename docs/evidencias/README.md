## Cómo tomarlas

Ventana completa del navegador, con la barra de direcciones visible: la URL es
parte de la evidencia porque identifica el repositorio. Sin recortar a la zona
de interés.

## Lo que no vale

- Capturas de otro repositorio o de un ejemplo de la guía.
- Capturas de algo que no existe todavía en GitHub.
- Recortes donde no se distinga de qué repositorio se trata.
